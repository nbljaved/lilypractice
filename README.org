Piano practice from LilyPond scores, in the spirit of Sightread and
PianoBooster: the real engraving with a cursor that follows the music, three
practice modes, scoring, loops, and the hand you are not practising played
for you. Native (Go, GTK 4, librsvg, ALSA), for Guix.

*A vibe-coded project, for personal use.*
It does what I need on my machines (Linux, with Guix).

#+begin_src sh
./run.sh testdata/bach-invention-01.ly   # build (in a Guix shell) and start
./run.sh -h                              # all flags
#+end_src

Everything else (modes, keys, MIDI, sound, tests, how it works) is in
[[file:README-for-ai.org][README-for-ai.org]].
